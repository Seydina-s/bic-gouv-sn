# Catalogue des erreurs

<!-- Généré depuis packages/shared-types/src/errors/error-catalog.ts : ne pas modifier à la main. -->
<!-- Mise à jour : pnpm errors:doc -->

Chaque erreur technique de la plateforme a ici son explication en français simple, affichée telle quelle dans le journal des erreurs de l'administration. Un code absent de ce catalogue est signalé « non répertorié » pour être ajouté.

Gravité : 🔴 utilisateurs bloqués · 🟡 fonctionnement dégradé ou à surveiller · 🟢 information.

| Code | Gravité | Quoi | Où | Impact | Que faire |
|---|---|---|---|---|---|
| `RESILIENCE_TIMEOUT` | 🟡 Jaune | Un service extérieur a mis trop de temps à répondre. | Appel à un service extérieur (source officielle, voix, IA, notifications…) | L'opération concernée n'a pas abouti ; l'app affiche la dernière version connue. | Si cela se répète, vérifiez l'état du service concerné dans la supervision. |
| `RESILIENCE_CIRCUIT_OPEN` | 🔴 Rouge | Un service extérieur est mis en pause après plusieurs échecs de suite. | Supervision des dépendances | La fonction qui en dépend passe en mode dégradé jusqu'au prochain essai automatique. | Vérifiez que le service concerné fonctionne ; la reprise est automatique. |
| `RESILIENCE_ABORTED` | 🟢 Vert | Une opération a été annulée avant la fin, par exemple parce que l'écran a été fermé. | App ou serveur | Aucun : c'est un comportement normal. | Rien à faire. |
| `API_CONFIG_INVALID` | 🔴 Rouge | Le serveur de l'API ne peut pas démarrer : sa configuration est incorrecte. | Serveur de l'API (démarrage) | Toutes les applications sont privées de nouvelles données. | Corrigez la variable de configuration indiquée dans le message, puis redémarrez. |
| `ROUTE_NOT_FOUND` | 🟢 Vert | Une adresse inexistante de l'API a été demandée. | API publique | En général aucun ; en grand nombre, peut signaler une app trop ancienne ou un abus. | Rien à faire, sauf si le nombre augmente brutalement. |
| `REQUEST_INVALID` | 🟢 Vert | L'API a reçu une demande mal formée. | API publique | La demande concernée est refusée. | Si cela vient de l'app officielle, prévenez l'équipe technique. |
| `NEWS_NOT_FOUND` | 🟢 Vert | Un article demandé n'existe pas ou n'est pas disponible dans cette langue. | API publique, actualités | L'utilisateur voit un message « article introuvable ». | Rien à faire, sauf si le nombre augmente (lien cassé dans une notification ?). |
| `NEWS_WITHDRAWN` | 🟢 Vert | Un article demandé a été retiré du site de la Présidence ; l'app ne le montre plus. | API publique, actualités | L'utilisateur voit « Cet article a été retiré par la Présidence ». | Rien à faire : c'est le masquage voulu d'un article retiré par la source. |
| `RATE_LIMITED` | 🟡 Jaune | Trop de demandes sont arrivées depuis la même adresse réseau. | API publique (protection contre les abus) | Les demandes en excès sont refusées une minute ; en cas de hausse soudaine, possible abus ou robot. | Si cela touche beaucoup d'utilisateurs d'un opérateur, prévenez l'équipe technique (seuil à relever). |
| `SERVICE_NOT_READY` | 🔴 Rouge | Le serveur de l'API tourne mais ne peut pas encore lire les articles. | API publique (sonde de disponibilité) | Le répartiteur de charge n'envoie pas de citoyens vers ce serveur tant qu'il n'est pas prêt. | Vérifiez l'accès au stockage des articles ; si cela dure, prévenez l'équipe technique. |
| `INTERNAL_ERROR` | 🔴 Rouge | Une erreur inattendue s'est produite dans l'API. | API publique | La demande concernée a échoué pour l'utilisateur. | Transmettez l'identifiant de la requête à l'équipe technique. |
| `INGESTION_SOURCE_UNREACHABLE` | 🔴 Rouge | Le site de la Présidence ne répond pas à la collecte des articles. | Collecte automatique (presidence.sn) | Les nouveaux articles n'arrivent plus dans l'app ; les articles déjà collectés restent visibles. | Vérifiez que presidence.sn est accessible ; la collecte reprend seule dès son retour. |
| `MAP_UNAVAILABLE` | 🟡 Jaune | Le fond de carte n'est pas disponible : le fichier des tuiles du Sénégal manque sur le serveur. | API publique (/v1/map) | La carte de « Près de moi » reste vide ; la liste des services et les itinéraires fonctionnent toujours. | Replacez le fichier des tuiles (procédure « fond de carte ») puis redémarrez l'API. |
| `PROCEDURE_NOT_FOUND` | 🟢 Vert | Une démarche demandée n'existe pas (ou plus). | API publique (/v1/procedures) | La personne voit un message « démarche introuvable » ; les autres démarches s'affichent. | Rien à faire si c'est ponctuel ; si cela se répète, vérifiez la collecte des démarches. |
| `ADMIN_SIGN_IN_FAILED` | 🟢 Vert | Une tentative de connexion au centre d'administration a échoué (mauvais e-mail, mot de passe ou code). | Centre d'administration (connexion) | La personne n'entre pas ; aucun accès n'a été donné. | Rien à faire si c'est ponctuel ; de nombreux échecs sur un même compte peuvent signaler une tentative d'intrusion. |
| `ADMIN_TOO_MANY_ATTEMPTS` | 🟡 Jaune | Un compte d'administration est bloqué 15 minutes après 5 tentatives de connexion ratées. | Centre d'administration (connexion) | La personne concernée doit attendre 15 minutes avant de réessayer. | Vérifiez avec la personne que c'était bien elle ; sinon, changez son mot de passe et consultez le journal d'audit. |
| `ADMIN_SESSION_EXPIRED` | 🟢 Vert | Une session du centre d'administration a expiré (30 minutes sans activité ou 8 heures au total). | Centre d'administration | La personne doit se reconnecter ; rien n'est perdu. | Rien à faire : c'est une protection normale. |
| `NOTIFICATION_SAME_PERSON` | 🟢 Vert | Une personne a voulu valider une notification qu'elle avait elle-même préparée. | Centre d'administration, notifications | La validation a été refusée : un envoi national demande deux personnes. | Demandez à une autre personne de l'équipe de vérifier et valider la notification. |
| `NOTIFICATION_NOT_PENDING` | 🟢 Vert | Une notification déjà validée ou annulée a été validée ou annulée une seconde fois. | Centre d'administration, notifications | Rien n'a été modifié ; la première décision reste valable. | Rechargez la page : une autre personne a sans doute déjà décidé. |
| `NOTIFICATION_ALREADY_PENDING` | 🟢 Vert | Une notification a été préparée pour un article qui en avait déjà une en attente de vérification. | Centre d'administration, notifications | Rien n'a été préparé : le même article ne peut pas partir deux fois à tout le pays. | Validez ou annulez la notification déjà en attente pour cet article. |
| `NOTIFICATION_NOT_FOUND` | 🟢 Vert | Une notification demandée n'existe pas. | Centre d'administration, notifications | L'action a été refusée ; rien n'a été modifié. | Rechargez la page des notifications. |
| `ERROR_GROUP_NOT_FOUND` | 🟢 Vert | Une erreur à marquer comme réglée n'est plus dans le journal. | Centre d'administration, journal des erreurs | Rien n'a été modifié : seules les 300 erreurs les plus récentes sont gardées. | Rechargez le journal des erreurs. |
| `NOTIFICATION_ARTICLE_UNKNOWN` | 🟢 Vert | Une notification a été préparée pour un article introuvable ou retiré. | Centre d'administration, notifications | Rien n'a été préparé : on n'annonce qu'un article officiel publié. | Choisissez un article dans la liste proposée. |
| `ADMIN_FORBIDDEN` | 🟡 Jaune | Un compte a tenté une action que son rôle ne permet pas. | Centre d'administration | L'action a été refusée ; rien n'a été modifié. | Si la personne a besoin de ce droit, un administrateur change son rôle ; sinon, consultez le journal d'audit. |
| `ACCOUNT_NOT_FOUND` | 🟢 Vert | Un compte d'administration demandé n'existe pas. | Centre d'administration, comptes | L'action a été refusée ; rien n'a été modifié. | Rechargez la page des comptes. |
| `ACCOUNT_SELF` | 🟢 Vert | Un administrateur a voulu changer son propre compte (rôle, désactivation ou second code). | Centre d'administration, comptes | L'action a été refusée : on ne peut pas se retirer ses propres droits, ce qui garantit qu'un administrateur reste actif. | Demandez à un autre administrateur de faire ce changement. |
| `ACCOUNT_EMAIL_TAKEN` | 🟢 Vert | Un compte a été créé avec une adresse e-mail déjà utilisée par un autre compte. | Centre d'administration, comptes | Rien n'a été créé : une adresse ne sert qu'à un seul compte. | Vérifiez l'adresse ; si la personne a déjà un compte, changez plutôt son rôle ou réactivez-le. |
| `ACCOUNT_ALREADY_ACTIVE` | 🟢 Vert | Un nouveau lien d'activation a été demandé pour un compte dont le mot de passe est déjà choisi. | Centre d'administration, comptes | Aucun lien n'a été créé ; le compte reste inchangé. | Rechargez la page : la personne a sans doute déjà activé son compte. |
| `ACCOUNT_ACTIVATION_INVALID` | 🟢 Vert | Un lien d'activation de compte est inconnu, déjà utilisé ou expiré (72 heures). | Centre d'administration, activation d'un compte | La personne ne peut pas choisir son mot de passe avec ce lien. | Un administrateur crée un nouveau lien depuis l'écran « Comptes » et le lui transmet. |
| `ACCOUNT_PASSWORD_REJECTED` | 🟢 Vert | Un mot de passe choisi à l'activation d'un compte est trop court ou trop long. | Centre d'administration, activation d'un compte | Rien n'a été enregistré ; le lien reste valable. | Choisissez une phrase de passe d'au moins 12 caractères. |
| `IDEMPOTENCY_KEY_REUSED` | 🟡 Jaune | Une même clé de protection contre les doubles envois a servi pour deux demandes différentes. | API (écritures : console, formulaires) | La seconde demande a été refusée ; la première reste valable, rien n'a été écrit deux fois. | Rechargez la page avant de recommencer ; si cela se répète, prévenez l'équipe technique. |
| `IDEMPOTENCY_IN_PROGRESS` | 🟢 Vert | Une demande a été envoyée une seconde fois alors que la première était encore en cours. | API (écritures : console, formulaires) | Le second envoi a été ignoré : l'action ne sera faite qu'une fois. | Rien à faire : attendez quelques secondes, puis rechargez la page pour voir le résultat. |
| `IDEMPOTENCY_KEY_INVALID` | 🟡 Jaune | Une demande portait une clé de protection contre les doubles envois mal formée. | API (écritures) | La demande a été refusée ; rien n'a été écrit. | Prévenez l'équipe technique : un outil envoie des demandes incorrectes. |
| `INGESTION_STOPPED` | 🔴 Rouge | La surveillance des nouvelles publications de la Présidence est arrêtée. | Collecte automatique (presidence.sn) | Les nouveaux articles n'arrivent plus dans l'app ; les articles déjà collectés restent visibles. | Relancez le service de collecte, ou prévenez l'équipe technique. |
| `INGESTION_QUARANTINED` | 🟡 Jaune | Un article collecté est incomplet ou mal formé : il n'a pas été publié. | Collecte automatique (presidence.sn) | Cet article n'apparaît pas dans l'app tant qu'il n'est pas corrigé. | Vérifiez l'article sur presidence.sn ; si la structure du site a changé, prévenez l'équipe technique. |
| `MEDIA_PROCESSING_FAILED` | 🟢 Vert | La photo d'un article n'a pas pu être récupérée ou préparée. | Collecte automatique (photos) | L'article est publié sans photo ; le texte reste complet. | Rien à faire : une nouvelle tentative a lieu au prochain passage. |
| `ADMIN_API_UNREACHABLE` | 🔴 Rouge | L'administration n'arrive pas à joindre l'API. | Centre d'administration, écran « État du service » | Les applications ne reçoivent probablement plus de nouvelles données. | Vérifiez que le serveur de l'API est démarré, puis vérifiez à nouveau. Si cela continue, prévenez l'équipe technique. |
| `ADMIN_API_INVALID_RESPONSE` | 🟡 Jaune | L'API répond, mais pas dans le format attendu. | Centre d'administration, écran « État du service » | Une mise à jour a peut-être été mal déployée. | Prévenez l'équipe technique. |
| `ADMIN_API_UNCONFIGURED` | 🟡 Jaune | L'adresse de l'API n'est pas configurée dans l'administration. | Centre d'administration (configuration) | L'état du service ne peut pas être vérifié. | Renseignez la variable API_URL de l'administration. |
